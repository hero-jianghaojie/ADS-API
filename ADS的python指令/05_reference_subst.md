# 第五章：Technology 层 —— `keysight.ads.subst`

`keysight.ads.subst` 包用于衬底（Substrate）和工艺技术定义。

## 导入

```python
from keysight.ads import subst
```

## 主要功能

- 定义层叠结构（衬底材料、厚度、介电常数）
- 设置传输线模型参数
- 管理工艺技术文件

## 示例索引

| 示例 | 说明 |
|------|------|
| `ex_make_substrate` | 创建衬底定义 |
| `ex_substrate_with_layout` | 衬底与版图结合 |
